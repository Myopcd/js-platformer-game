# JS Vertical Platformer

Браузерный 2D-платформер, написанный на чистом JavaScript (ES6+ Modules) и HTML5 Canvas без использования сторонних игровых движков.

**[Играть онлайн (Live Demo)](https://github.io)**

## Реализованные механики и архитектура
* **Модульная структура:** Разбил логику по отдельным модулям, чтобы не мешать физику игрока, генерацию уровня и отрисовку кадров в одном файле (`Player`, `Level`) и главный игровой цикл (`main.js`).
* **Физика и коллизии:** гравитация, импульс прыжка и односторонняя AABB-коллизия при приземлении на платформы.
* **Динамическая камера:** плавное вертикальное слежение за высотой последней опоры игрока через `ctx.translate()`.
* **HUD и хранение данных:** подсчет собранных предметов, таймер прохождения (`performance.now()`) и сохранение топ-3 лучших результатов в `localStorage`.

## Управление
* **Влево / Вправо:** `A` / `D` или стрелки `←` / `→`
* **Прыжок:** `W`, `Space` или стрелка `↑`

## Локальный запуск
1. Склонируйте репозиторий: `git clone git@github.com:Myopcd/js-platformer-game.git`
2. Откройте проект в VS Code и запустите через расширение **Live Server**.
